# V7 助手 Agent 架构与能力说明

本说明对应现有 Vue/FastAPI 工作台的 C6.21 已接受核心与D1.3操作目录增量。D-04补充当前工作区目录和持久全文阅读：原请求的固定片段与当前全文独立，阅读不调用生成模型，不增加Agent设备命令权限。它与实训教练提示词、助手请求计量说明共同随仓库交付。运行不依赖开发者的个人技能目录或 `.runtime` 评测脚本。

## 请求与信任

`backend/modules/ai_text/router.py` 负责认证、请求登记和持久结果；同步与 SSE 适配进入同一 `LLMService` 事件内核。客户端页面信息提供问题背景，角色、环境、观察归属、保护策略及执行权限由服务端重新核验。

`trusted_context.py`、`owned_history.py` 和 `history_summary.py` 保留对象、更正、原时点和来源边界。历史回答可以解释，不能自动成为当前设备事实；旧无证明记录也不会被补写为已核验观察。长历史按边界整条省略。

## 六种技能

实际注册表是 `backend/modules/ai_text/skills.py`，版本 `v7-d1.2`。`助手技能清单.json` 是该源码的发布摘要，工具权限仍以运行时注册表和执行器为准。

D-01/02同步实训的新步骤核对、环境绑定和笔记路径。`核对本步`由用户在会话中操作，不自动成为Agent的新执行工具。未核验会话可得到已知按钮的固定只读说明，但不因此启用模型、工具、配置草稿或绕过会话归属。新内容和环境要求从会话快照读取，不随当前实验修改漂移。

| 技能 | 任务 | 执行边界 |
|---|---|---|
| page_help | 解释当前页面、动作和导航 | 按实际能力目录，通常一轮生成，不读设备或教材 |
| knowledge_answer | 教材概念、比较和配置原理 | 单次检索，引用实际片段；未知明确说明 |
| live_evidence | 解释已核验观察或按需读取 | 核验对象、时间、模式、环境和完整性；不拿教材补现场 |
| troubleshooting | 根据实际反馈逐步排查 | 确认两端、保留业务范围；证据足够或无新增信息即停 |
| config_draft | 提供待审阅配置 | 明确目标/环境/保护校验；不提供执行工具，原下发确认链继续有效 |
| lab_coach | 解释本人实训目标、步骤、验证和报告 | 固定实验/会话版本，不代执行，不把学员自报等同核验通过 |

技能按需选择回答框架、证据需求和工具子集。它们采用随源码校验的 Python 元数据，不加载任意外部脚本，也不因文字声称“管理员”而授予权限。能力目录覆盖现有 17 个业务路由；页面改名或动作变化需同步更新目录与操作手册。

## 工具、循环与输出

`agent_tools.py` 复用现有设备查询、受限 display、锁与授权。工具参数有 schema，结果保留真实状态、对象和完整性；失败、部分、空和完整零值分开。标准与诊断路径可根据实际反馈继续选择下一读，重复结果、超时、取消或预算耗尽时退出。

| 档位 | 取证轮数上限 | 工具尝试上限 | 逻辑生成上限 |
|---|---:|---:|---:|
| direct | 0 | 0 | 1 |
| standard | 2 | 6 | 4 |
| diagnostic | 3 | 9 | 6 |

逻辑生成包括规划、私有初稿、定稿和草稿提取；失败/备用提供商 HTTP 逐次另计。工程验证累计费用和调用没有上限，这些单请求边界用于防循环。档位升级不清零用量，不要求每次花满。

`draft_guard.py`、`draft_environment.py` 与流式防护在首次展示前核验正文和结构化草稿。未知、漂移或受保护环境不给可执行草稿。模型工具协议与隐藏推理不作为用户正文。草稿只能进入原有表单；创建、审批、执行、回读是不同步骤。

## 检索、引用与取舍

检索保留现有 provider 接口。本地 provider 以仓库 Markdown 语料、块结构和 BM25 检索为底座；AnythingLLM 适配使用其搜索接口，不额外调用 ask 隐含生成。候选重排限定同协议、主题覆盖及缩写上下文，显式 SSH 配置问句在原候选预算内优先召回用户认证与公钥正文。完整教材原文保持不变。

`context_bundle.py` 固定本次片段与版本；`reviewed_source_notes.json` 的独立审校按精确原文触发并单独显示。带服务端审校的知识回答可使用私有初稿与定稿两阶段，增加一次生成和等待，避免把原文的简化/旧范围推广为普遍建议。无审校的一般路径不强制两阶段。

引用回读绑定原请求、原片段及文档权限，不跳到后来检索的不同正文。前端兼容 `[5]`、`[n:5]`、`[n5]` 等有界编号；代码中的相似文本保持字面。无匹配引用明确提示，正文不会被改写成另一个模型答案。

缓存只复用授权范围、语料和配置身份一致的检索/工具结果，不把未知字段补零；原请求重放不再生成或重复采集。词法/相邻段落增强、统一扩张提示等候选依据同题效果取舍；没有收益的实验不进入默认流程。没有引入通用多 Agent 框架或额外服务迁移。

## 失败、计量与交付限制

请求预留、取消、持久终态、断线与重开恢复由 `request_lifecycle.py`、`request_store.py` 和前端 `aiCopilot.ts` 协同处理。读取旧报告/原回答不生成新版本；明确“重新生成”才创建新结果。保存失败与生成失败分别提示。

耗时、提供商派发和真实 usage 的口径见《助手请求计量说明》。服务端首正文不等于浏览器首字；未返回用量为未知，不能当成零成本。

当前本地教材与真实 DeepSeek 开发验证、独立测试浏览器验收均有版本化证据。它们不证明所有型号的 CLI 支持，也不替代三台真实联网设备联调、外部 AnythingLLM/Ollama 实例验证、接收方自有凭据首次配置及真实初学者测试。迁移 0012 需按交付流程显式升级，现用库不会被本说明或测试自动迁移。
