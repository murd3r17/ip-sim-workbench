# IP仿真运维管理工作台 · 用户手册

适用：V7.0 增量工作台，2026-11-07。安装与首次配置见同目录《接管指南》和《AnythingLLM知识库部署与运维指南》；本手册说明进入系统后的操作。

## 1. 登录后从哪里开始

用管理员为你创建的账号登录。首页是统一「工作台」，网络维护工具和实训共用这一个入口。

第一次使用可依次做三件事：

1. 在工作台查看设备、告警和待处理工作；注意显示的采样时间。
2. 进入「设备」，搜索目标，点该行「只读观察」，查看接口状态与地址，或选择 OSPF 邻居、OSPF 路由。采集后保留记录编号，便于回看。
3. 在右侧助手询问当前结果的含义；开始练习时从「实训」选择已有实验。

工作台的「刷新状态」读取已有汇总；设备健康检查、只读事实采集、监控采集和终端连接是不同动作。设备在线、SSH 可连接、协议正常、业务可达也需要分别判断。

登录受到访问频率限制；提示稍后再试时，等窗口结束后重试。右上角用户名菜单可退出登录。不要把登录密码或模型密钥发到对话里。

## 2. 页面入口与角色

| 入口 | 用途 |
|---|---|
| 工作台 | 已保存环境状态、设备与拓扑、待处理工作和继续入口 |
| 设备 / 拓扑 / 终端 | 登记设备、观察事实、核对邻接、打开 SSH |
| 配置下发 / 变更审批 / 配置版本 | 编辑与校验配置、管理任务、保存及比较快照 |
| 监控 / 告警 | 查看采样、用途与预期、历史趋势和处理记录 |
| 实训 / 知识库 | 进行或回看练习、阅读教材与回答来源 |
| 环境映射 | 管理员维护现场角色、接口、地址和保护项 |
| 系统管理 | 管理员查看系统信息、配置、审计、后台任务和日志文件 |

普通用户可以使用业务页、助手和自己的实训、任务、报告；本人记录的操作仍受状态、设备占用和风险规则约束。设备增删、实验管理、环境映射和系统管理等动作需要管理员。没有权限的管理入口会隐藏或禁用，直接访问也会被拒绝。

## 3. 设备与只读观察

「设备」页可搜索设备名、管理 IP。点一行会把对象带给助手；点「只读观察」打开该设备的抽屉。

- 选择「接口状态与地址」「OSPF 邻居」或「OSPF 路由」，点「采集只读事实」。这里只执行服务端登记的只读命令。
- 环境映射可选；要按具体角色的预期核对结果时，先选对应环境。
- 「最近证据」读取已有记录；点击记录可回看当时的结果、时间、完整性和受控原文。
- 「与本环境预期比对」使用所选记录与绑定的预期；记录归属、模式、时效或完整性不合格时无法判通过。
- 「健康检查」与观察采集分别执行；只打开观察抽屉不会重新采集。

管理员可用「添加设备」登记管理 IP、SSH 端口、类型、型号和所属拓扑。行内「更多」包含编辑、删除及其他去向；存在关联记录时，删除可能被拒绝。所属拓扑不能在设备编辑里随意更换。

## 4. 拓扑、基线与运行态

拓扑中的基线关系、手工登记关系与本次 LLDP 观察分别显示。LLDP 邻接可能经过共享二层段；一条线不能证明完整物理网络或业务可达。

- 「更多 → 新建拓扑」建立登记对象。
- 「更多 → 导入 Excel 基线」先预检，再明确确认导入；预检成功本身不保存。
- 只有设备、没有链路的文件，需明确勾选「仅设备库存（链路尚未验证）」。这不产生已验证链路；有链路的文件或已有链路历史不适用该方式。凭据列不作为导入内容。
- 「运行态校验」读取设备邻接，对照基线并展示覆盖、未观察到、非基线邻接、库存外邻居及失败项。零基线、零观察不能当作网络完整或正常。
- 「确认 LLDP 基线」在本次观察满足条件并人工确认后保存基线；不会自动建立未纳管资产。
- 「保存草稿」保存布局；「发布到总览」发布展示布局。布局与链路基线是不同记录。
- 「更多 → 版本记录」查看和回滚拓扑基线版本。回滚前核对当前拓扑与版本；这不是设备配置回滚。

同一拓扑刷新失败会保留旧图并提示可能陈旧；切换对象、空目录或新对象读取失败时，不沿用上一对象的图、节点动作或草稿位置。

## 5. WebSSH 终端与设备占用

从设备行点「终端」会进入并连接对应设备；从侧栏进入「终端」则需选设备、点「连接」。先确认设备名称和地址，再输入命令。切换或结束操作时点「断开」。

终端支持粘贴；多行会逐行发送，需在粘贴前检查所有命令。助手输出配置文本也需要由用户核对和操作。

遇到占用提示时：

| 提示 | 处理 |
|---|---|
| 设备终端被占用 | 先断开该设备的活动终端，再采集、核验或下发 |
| 设备存在待执行配置任务 | 到变更审批/下发任务详情检查持锁任务，按状态完成或取消 |
| 终端并发数达到上限 | 关闭不用的会话后再连接 |
| 认证失效 | 重新登录；核对设备凭据时由管理员处理 |
| 关闭或释放失败的旧锁 | 管理员在「环境映射 → 终端锁核查/恢复」核查；活动终端不能强行当作孤儿锁释放 |

## 6. 使用右侧对话助手

助手随页面提供解释、资料引用、允许范围内的只读查询及配置草稿。它会按问题选择所需能力；简单页面说明不需要每次检索教材或访问设备。

发送前看清当前页面和对象标签；跨页面保留的设备仍会被带入下一条问题。不需要该对象时，用标签旁独立的关闭按钮移除。可以直接问「这里怎么做」「这些接口状态说明什么」「这份配置差异有什么影响」。

- 回答中的「来源」可打开原回答保存的片段；「阅读当前全文」查看现在的资料版本，两者可能不同。
- 「文件」可以附加允许类型的文本或图片；图片解读需管理员配置可用的视觉模型。页面会说明当前是否可用。
- 「附带配置草稿」生成可编辑文本；生成草稿不创建或执行变更。
- 等待、检索或生成期间可停止；停止后先看当前请求状态，再决定是否重试，避免重复请求。
- 「历史」可重新打开已保存对话；读取历史不重新请求模型。

助手的说明、模型自评和用户口头汇报不直接成为技能通过证据。证据不足、资料不支持、设备占用或依赖不可用时，按回答给出的下一步补齐事实。

## 7. 知识库阅读与引用

「知识库」提供资料目录、教材分组和检索。当前项目语料目录包含 10 本教材对应的 135 篇拆分正文；实际可检索范围以所选知识服务状态和同步结果为准。

先筛选资料，点击标题打开「资料全文」。左侧目录可定位章节，正文支持排版阅读或原始文本；点「返回原页面」继续工作。缺少页码或大小时显示未知，不据此补造教材页码。

「检索资料」可查看命中片段和来源。片段相关分数表示检索排序，不代表答案正确率。资料来自教材或外部文本，里面的示例接口、地址及命令应结合现场环境核对。

更换知识 provider、同步语料或删除文档由管理员按部署与运维指南处理；阅读不要求删除或重新导入资料。

## 8. 配置下发、审批与执行结果

1. 进入「配置下发 → 新建任务」，选择目标设备并编辑配置。
2. 需要时展开「AI 辅助」生成/审查草稿，再做「静态校验」。静态校验发现的命令行可定位；未覆盖项仍需核对。
3. 点「创建任务」保存待确认记录。
4. 到任务详情或「变更审批」核对配置、目标、风险与锁状态，完成相应确认。
5. 再执行任务，查看保存的执行、回读与恢复结果。

确认只记录结论并取得所需写锁；不等于配置已到设备。执行性质以每次任务保存的模式为准，不能用当前全局开关解释旧任务。真实写入需要接收方现场的设备、凭据、白名单和风险条件均满足，不复用开发机器上的设备编号或地址。

批次在「任务管理」中查看；配置快照产生的独立回滚任务在「变更审批」中完成。默认筛选看待处理任务，终态可选「已完成」「失败」「已回滚」回看。取消未终结任务是否释放锁、能否继续，查看实际响应。

下发、审批、快照和后台任务中的「记录来源」筛选可区分登记业务入口、明确测试和来源未明；恢复「全部来源」可再看到被筛掉的记录。名称看起来像测试不代表可删除，来源未明也不自动归类为测试。

## 9. 配置快照、差异与回滚

「配置版本 → 配置快照」先选择采集设备，再点「采集并保存配置」；读取当前配置会连接设备，但不下发配置。

「配置差异比对」分别选择快照 A、B；设备、版本和时间均需核对。跨设备比较会提示对象不同。「本地 A / B 文件比对（不上传）」可比较本次浏览器会话中的两个文件，保留行号和上下文；大小写等真实差异不会被随意忽略。

可以查看差异、导出结果或请求「AI 说明差异」。AI 使用受控差异，读取比对结果与请求模型是分开的动作。导出副本遮蔽凭据；脱敏后的相同文本不能证明原秘密相同。

快照的「回滚」生成高风险任务，仍需在「变更审批」完成确认、执行和回读流程；不会立即修改设备。配置变更日志可按任务项 ID「查询」。

## 10. 监控与告警

「刷新数据」更新已有采样和图表；「触发采集」获取新样本，「触发巡检」启动巡检流程。自动采集是否启用以页面提示和有效配置为准。趋势图按设备显示历史，注意图表所示采样时间和缺失区间。

「查看端口观察」分开呈现物理、协议、管理关闭、用途、预期与新鲜度。用途未知、闲置 down、管理关闭和预期启用但异常是不同情况；历史告警不会因修改用途而被抹除。

告警「确认」表示有人接手，「关闭」表示结束处理记录；两者都不直接证明设备或业务恢复。查看详情并核对新的设备事实。监控阈值由管理员在系统配置中查看当前有效档位，不能只凭一条已保存配置认定已生效。

## 11. 实训：继续、核对与保存

从「实训」搜索实验，点「开始实训」或「继续实训」。已有七项内置协议实验及巡检演示；每个实验的先修、目标和支持范围决定能否开展，列表就绪不代表所有真实协议已验证。

关闭「实训会话」窗口不会结束实验，可从「我的实训会话」继续。历史会话只读回看，不重新绑定活动终端。实验行「更多操作」中的「自由练习」建立练习记录，不创建隔离设备实例；故障场景记录也不等于已经向设备注入故障。

按步骤采集观察后点「核对本步」，使用服务端保存的观察与该会话固定的环境、内容版本比较。支持规则能返回通过、未通过或无法判断；未支持的协议细节、计时和业务转发需人工检查。历史活动分数不能作为已掌握技能的结论。

笔记与步骤记录需要保存。发生并发修改冲突时，先读取差异再决定如何处理；不要用一份旧草稿覆盖另一窗口的新版本。

复盘与导出按下面顺序：

1. 想包含当前草稿，先保存笔记。
2. 点「查看复盘」，在「已保存复盘版本」选择需要的成功版本。
3. 点「导出记录」，选择「操作日志（JSONL）」或「已保存笔记与复盘（JSON）」。

读取、切版本和导出都只查已保存记录，不重新检索或请求模型。生成/重新生成复盘才会请求模型。失败尝试不代替旧成功版本；导出失败可从原菜单重试。已经下载的文件不会随页面切版本改变，需要重新导出。

整合 JSON 包含当前已保存笔记/步骤修订、操作日志与所选成功复盘。报告的原生成来源可能早于当前笔记；原输入指纹与导出片段指纹用途不同。未保存草稿不在导出内，导出副本会脱敏。

## 12. 管理员：环境与系统

环境映射维护角色对应的设备、接口、用途、地址掩码、保护项，以及各角色自己的预期邻居和路由。按实际现场填写，不能把某套教材的 R1/R2/R3 作为所有环境的默认。点「预检」读取事实后由服务端判断状态；手工填写预期不算验证通过。

「系统信息」展示运行、依赖与凭据配置状态；健康探测不等于回答质量或设备联调通过。

「系统配置」先看「当前进程有效配置」，展开逐项有效值、来源与生效方式。下方已保存键值表表示数据库里存在这些行；是否有消费者、何时生效，以有效配置说明为准。支持的模型覆盖可由后续新请求读取；启动项需按部署流程修改启动环境并重启。已有凭据编辑时留空保留原值，页面不会回显秘密。

「刷新配置快照」只读；「测试模型连通性」才会请求模型依赖并记录审计。知识检索、视觉模型和对话模型是不同链路，应分别核对。

「审计日志」可筛选并查看操作详情，原始动作码保留供核对。「后台任务」展示已进入后台任务表的记录，并提供下发、采集巡检和实训入口。「日志文件」可刷新列表并在线查看所选文件；导出诊断资料前先检查敏感信息。

## 13. 读取失败、断线与窗口调整

首次读取失败表示最新数据未知，不等于零条、设备正常或记录被删除。保留的列表、图形和记录可能陈旧，重试成功后才更新。不要因为读取失败重新导入库存、新开会话或删除历史。

| 区域 | 重试入口 |
|---|---|
| 设备、终端或表单设备选项 | 错误提示中的「重试设备列表」 |
| 拓扑/环境选项 | 「重试拓扑列表」「重试环境列表」 |
| 下发任务、模板、快照、拓扑版本 | 「重试任务列表」「重试模板列表」「重试快照列表」「重试版本记录」 |
| 审批、环境、实验、我的实训会话 | 对应区域的「刷新」 |
| 配置变更日志 / 最近证据 | 「查询」/「最近证据」 |
| 日志正文 | 「重试读取」 |

刷新列表只读保存记录，不连接终端、不触发设备采集、不执行变更、不调用模型。操作提交后断线，应先查原任务或请求状态，确认是否已经保存/执行，再决定是否重试。

以最大化窗口工作时可同时查看工具与助手。窗口变窄或放大到 200% 时，页面和长表格可分别滚动；右上角「AI 助手」可展开或收起右栏。弹窗正文较长时在正文滚动，核对对象后再使用底部动作。


### 监控、告警与审计的读取恢复

监控、告警与审计读取失败：监控的「刷新数据」重读统计、最近告警、巡检任务和趋势；拓扑选项失败用「重试拓扑列表」。告警页设备选项失败用「重试设备列表」，告警和审计记录失败用所在页「刷新」。失败不代表无告警、无任务、无审计或当前健康；同一对象已显示快照保留并提示可能陈旧，新对象不会显示旧对象的图表与巡检。告警/审计快速换筛选时，迟到旧回包不会替换新选择的结果；出现失败应重试成功后再判断最新范围。刷新不是触发采集、巡检、确认、关闭告警或执行变更。
