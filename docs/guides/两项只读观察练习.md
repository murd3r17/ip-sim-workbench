# 两项只读观察练习

使用现有实训工具中的OSPF完整版，不新增实验或学习入口。管理员先建立包含各角色的环境映射、保护项、互联/环回用途与每角色预期，完成预检，再从实验行的步骤数量链接保存环境绑定。未具备前提时可以阅读；核对结果会显示缺项，不用猜。

普通用户从左侧「实训」进入，开始或继续对应会话，展开「步骤核对」。这两项练习只使用已有固定只读命令，不需要写设备权限；不进入终端执行配置，不做故障注入。

## 练习一：接口与地址，10–20分钟

1. 选择第1步“互联与环回地址核对”，先读本会话的版本与角色映射。
2. 点「采集当前观察」，查看每角色的接口记录；保留互联/环回接口名、地址掩码、采集时间与观察ID。
3. 选择本次每角色一份接口观察，点「核对本步」。若用途、精确地址、两类Up状态或观察条件不符，按结果回看原记录，不把其他接口的Up替代目标。
4. 在「连续任务 · 笔记与步骤」写下已知事实和仍不能判断的内容，点「保存笔记/步骤」。关闭再打开会话可回看。

本次能比较指定接口与地址，不据此宣布路由协议或业务正常。

## 练习二：邻居与路由，10–20分钟

1. 在同一会话选第3步“邻居、路由与环回互通”，本练习只完成其中只读事实核对，不执行ping或配置变更。
2. 点「采集当前观察」，取得每角色的OSPF邻居和路由记录；核对目标邻居ID、状态和精确前缀，不只找Full或10.0.0字样。
3. 选择每角色、每类各一份记录，点「核对本步」。保留不一致、缺失或过期信息；观察在会话开始后采集，且距本次核对不超过五分钟。长会话可重新采集新记录。
4. 把“接口可用”“目标邻居符合预期”“目标路由符合预期”和“业务转发未验证”分别记入笔记。需要报告时再显式生成，回看已有报告不会重新生成。

全程没有技能通过判定。未支持的协议、计时、进程/区域、下一跳、Cost、人的理解和实际业务转发仍需相应证据或教员复核。真实设备与模拟设备记录的模式来自服务端，不把练习成功当成最终交付验收。
