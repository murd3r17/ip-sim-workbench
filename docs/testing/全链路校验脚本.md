# 全链路校验脚本

可复跑的 live 校验，用来确认工作台六组件（MySQL / MinIO / 后端 / 前端 / Ollama / AnythingLLM）以及 **LLM、知识库、真 SSH** 真在工作，而不是接口 200 但内容已静默降级。

## 用法

前置：先跑 `scripts\start-local-windows.ps1`（或确认六端口已监听）。

```powershell
cd <repo>
$env:PYTHONPATH = "<repo>\backend"
.\backend\.venv\Scripts\python.exe backend\scripts\verify_full_stack.py
```

- 控制台：每项 `OK` / `FAIL` / `LIMIT`
- JSON 报告：`.runtime/logs/verify_full_stack.json`（`.runtime/` 已 gitignore）
- 脚本会创建再删除自己造的实训会话，避免实训页留垃圾数据
- **不打印** API Key、设备口令、JWT

## 为什么不能只看 HTTP 200

以下路径失败时接口仍可能返回 200：

| 降级点 | 特征串 / 表现 |
|--------|----------------|
| LLM `FallbackProvider` | 正文含 `当前AI服务不可用，请稍后重试。` |
| 实训 hint 本地模板 | `summary` = `已根据当前训练进度生成步骤提示。` |
| 实训 hint 教练 JSON 失败 | `summary` = `已根据当前训练场景给出下一步建议。` |
| 实训 report 本地模板 | `summary` = `已根据训练过程、操作记录和故障注入生成复盘摘要。` |
| 知识库 search 异常 | `sources=[]` 仍 200 |
| `GET /health` 的 llm | 不读 `system_config.llm.*`，只反映 `.env` |

脚本对生成/检索分项断言**内容特征**，不是只看状态码。

## 分项

1. **端口与进程**：13307 / 9002 / 8000 / 5173 / 11434 / 3001
2. **`GET /api/v1/health`**：mysql / llm / minio / ollama / knowledge 五项 `healthy`，整体 `healthy`
3. **登录**：`ADMIN_USERNAME` / `ADMIN_PASSWORD`（根 `.env`）→ token
4. **Ollama 真嵌入**：`POST 127.0.0.1:11434/api/embed`，模型 `nomic-embed-text`，向量维度 > 0（不经 AnythingLLM）
5. **知识库健康**：`available=true`，`document_count=135`
6. **知识库真检索**：`POST /api/v1/ai/knowledge/search`，query 如 OSPF Silent-Interface；`sources` 非空且含 score/text
7. **LLM 真生成**：`POST /api/v1/ai/generate-cli`，输出不含「当前AI服务不可用」，`commands` 非空
8. **LLM 配置来源**：读 `system_config` 的 `llm.*`，标明生效值来自 `.env` 还是 DB（health 不体现这层）
9. **Copilot 工具 + 真设备**：`POST /api/v1/ai/copilot/chat/stream`，SSE 出现 `run_display_command` 且回显含 VRP/Huawei
10. **实训闭环**：开会话 → 写操作日志 → `/hint`（`sources` 非空且 summary 不是降级模板）→ `/report`（非本地模板）→ 评分 → 结束 → **删除测试会话**
11. **设备真 SSH**：R1/R2/R3 只读 `display version` + `display ospf peer`（password 失败再 keyboard-interactive）
12. **已知限制（不算 fail）**：故障注入只写 `fault_injection` 表、不下发设备；`DEPLOY_SIMULATE_ONLY=true` 时配置下发为 simulated

## 与回归测试的关系

| 入口 | 作用 |
|------|------|
| `pytest tests -q` | 后端单测（SQLite 内存，不打真设备/真 LLM） |
| `npx vue-tsc --noEmit` | 前端类型 |
| `npx playwright test` | 冒烟（登录 / 知识库页「可用」 / 下发页） |
| `verify_full_stack.py` | **现网**全链路，识破静默降级 |
