R1 设备配置

```cli
sysname R1
```

ipv6

router id 10.10.10.1

```cli
ospfv3 1
```

```cli
router-id 10.10.10.1
```

```cli
interface GigabitEthernet0/0/2
```

ipv6 enable

```cli
ip address 10.0.12.1 255.255.255.0
```

ipv6 address 2001:DB8:12::1/64

```cli
ospfv3 1 area 0.0.0.0

interface GigabitEthernet0/0/3
```

ipv6 enable

```cli
ip address 10.0.11.2 255.255.255.0
```

ipv6 address 2001:DB8:11::2/64

```cli
interface LoopBack0
```

ipv6 enable

```cli
ip address 10.10.10.1 255.255.255.255
```

ipv6 address 1::1/128

```cli
ospfv3 1 area 0.0.0.0

bgp 65100

peer 10.0.11.1 as-number 65001 peer 10.10.10.3 as-number 65100 peer 10.10.10.3 connect-interface LoopBack0 peer 3::3 as-number 65100 peer 3::3 connect-interface LoopBack0

peer 2001:DB8:11::1 as-number 65001
```

ipv4-family unicast

```cli
undo synchronization

peer 10.0.11.1 enable peer 10.10.10.3 enable peer 10.10.10.3 next-hop-local
```

ipv6-family unicast

```cli
undo synchronization

peer 3::3 enable peer 3::3 next-hop-local peer 2001:DB8:11::1 enable

ospf 1

area 0.0.0.0 network 10.0.12.1 0.0.0.0 network 10.10.10.1 0.0.0.0

return
```
