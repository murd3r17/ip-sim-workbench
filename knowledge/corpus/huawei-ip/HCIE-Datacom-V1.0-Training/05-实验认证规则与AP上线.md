# 实验：认证规则与AP上线配置

## 认证规则、授权结果与授权规则

- 配置认证规则可以对接入网络的客户端和用户进行认证，保证网络的安全。
- iMaster NCE-Campus 存在缺省认证规则 Default，使用本地数据源进行认证。

- 配置授权结果后，还需要与创建的站点进行绑定。
- iMaster NCE-Campus 存在缺省授权结果“允许接入”和“拒绝接入”，缺省模板绑定所有站点，不可修改和删除。

- 授权规则所定义的是各种条件，当满足这些条件时，用户将获得相应的授权结果（即终端用户认证通过后具备哪些权限由授权结果指定）。
- iMaster NCE-Campus 存在缺省授权规则 Default，授权结果为拒绝接入，缺省模板支持修改，可以修改为其他授权结果。

## WLAN 业务实验概述（分布式网关 / 随板 AC）

在分布式网关方案中，若 Fabric 采用 VXLAN 到汇聚组网，Border 设备作为随板 AC，则 AP 需要在 Border 上线，并通过 Border 设备管理 AP。

总体目标是让园区内的 AP 释放一个 SSID，用于供无线用户接入，而且用户接入该 SSID 后需进行 Portal 认证。

> （原图：HQ 站点拓扑示意——iMaster NCE、Border 随板 AC、Edge_1/Edge_2、ACC_1/ACC_2、AP、PC1～PC3；Border 管理地址 172.16.20.254，管理 VLAN 2）

### 任务与配置步骤概览

**AP 上线**

1. 在站点 HQ 中添加 AP，并将 AP 分配给 Border。
2. 创建 AP 上线管理网段和管理 VLAN。
3. 设置无线 PnP 管理 VLAN。
4. 配置 Border 的 CAPWAP 隧道源接口。

**控制器侧无线业务配置**

1. 创建无线认证，配置 Portal 认证相关信息。

**无线业务下发（Border 的 Web 界面）**

1. 配置 SSID 模板。
2. 配置 VAP 模板，引用 SSID 模板、认证模板。
3. 配置 AP 组引用 VAP 模板。

## AP 上线：添加设备并分配 Fit AP

在“设计”→“设备管理”中为站点 HQ 手动添加设备，协议类型选择“NETCONF 协议”，通过 ESN 码添加 AP。此时 AP 还未上线，状态为未注册。

在“配置”→“站点配置”中选择交换机的“管理 Fit AP”功能，点击 Border，再点击增加，将 AP1 分配给 Border。

| 名称 | 关联 | 说明 |
|------|------|------|
| AP1 | HQ / Border | 通过 ESN 添加的 Fit AP |

## AP 上线：创建管理子网

在“配置”→“站点配置”中选择交换机的“子网”功能，创建子网，用于 AP 上线。通过该子网，AP 可获得 AC 地址及控制器 IP 地址。

设备：Border。

| 配置项 | 示例 / 说明 |
|--------|-------------|
| 子网名称 | ap |
| VLAN ID | 管理网络 VLAN（建议不要与业务 VLAN 冲突） |
| IP 获取方式 | 手动 / 自动 |
| IP/掩码 | 172.16.20.254/24 |
| 网关地址 | 172.16.20.254 |
| DHCP | 开启 |
| DNS 服务 | 按规划配置 |

开启 DHCP 功能，并将 AP 设置为 Fit AP。

## AP 上线：无线 PnP 管理 VLAN 与 CAPWAP 源地址

在“配置”→“站点配置”中选择站点的“管理 VLAN”功能，设置 Border 的无线 PnP VLAN。

| 配置项 | 说明 |
|--------|------|
| 设备名称 | Border |
| ESN | 设备序列号 |
| 自协商管理 VLAN | 按规划 |
| 无线自协商管理 VLAN | 按规划 |
| 管理 VLAN | 默认或其他规划值 |
| 上行口 PVID 使能 | 按规划 |
| 上行口自动放行 | 按规划 |

最后在 Border 的 CLI 中设置 CAPWAP 隧道源地址。AP 即可通过 VLANIF2 的地址池获取 IP 地址、AC 地址、控制器地址，并成功在 Border 和控制器上注册，此时 AP 状态为正常。

| 名称 | ESN | 设备型号 | 状态 |
|------|-----|----------|------|
| AP1 | （按实际） | AirEngine 等 | 正常 |
