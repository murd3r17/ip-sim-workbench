# 实验：控制器侧无线认证配置

## 创建无线认证

在“配置”→“站点配置”中选择交换机的“无线认证”功能，创建无线认证。

以销售人员的无线业务为例，主要配置项包括：

| 配置项 | 说明 |
|--------|------|
| 名称 | 无线认证名称 |
| SSID | 无线网络名称 |
| 认证方式 | 开放网络 / 半开放网络等 |
| 默认放行规则 | 按策略选择 |

## 选择认证策略与安全认证策略

1. 选择认证策略。
2. 选择安全认证策略。

常见选项包括：

- Portal 认证
- Portal 免认证有效期（单位：小时）
- IPv6 终端认证
- 逃生策略（需确认已阅读逃生策略告知，并知晓各类逃生策略的内容和风险）

逃生策略典型选项：

- 允许用户接入，不需要认证
- 允许已认证用户继续使用网络，不允许新用户接入
- 允许用户接入，不需要认证，使用自定义逃生策略

## 选择无线认证设备

选择需要下发该无线认证配置的设备（如 Border / 随板 AC 等），完成控制器侧无线认证创建。
