# 配置 Fabric 网络与逻辑 VN

## 配置用户接入认证模板

单击控制器的“Fabric 网络 > 网络规划 > 策略模板”页面，分别创建和配置 RADIUS 服务器模板、Portal 服务器模板和认证模板。

| 任务描述 | 详细操作步骤 |
| --- | --- |
| 创建 RADIUS 服务器模板 | 1. 选择 RADIUS 服务器类型。推荐采用 iMaster NCE-Campus 内置的 RADIUS 服务器。<br>2. 配置 RADIUS 服务器地址。如果采用 iMaster NCE-Campus 内置的 RADIUS 服务器，则不需要配置。 |
| 创建 Portal 服务器模板 | 1. 选择 Portal 服务器类型。推荐采用 iMaster NCE-Campus 内置的 Portal 服务器。<br>2. 配置 Portal 服务器 URL。如果采用 iMaster NCE-Campus 内置的 Portal 服务器，则不需要配置。 |
| 创建用户认证模板 | 1. 选择用户认证方式，常用的包括 802.1X 认证、MAC 认证和 Portal 认证。一个模板可以包含多种认证方式。<br>2. 选择需要绑定的 RADIUS 服务器模板或者 Portal 服务器模板。 |

## 配置 Fabric 网络

Fabric 是使用 VXLAN 技术构建在物理网络之上的资源池化网络。

> （原图：HQ 站点拓扑示意——Border、Edge、Edge_2、ACC、AP1，以及外部网络、网络服务资源与 iMaster NCE。）

| 任务描述 | 详细操作步骤 |
| --- | --- |
| 配置 Fabric 网络 | 1. 创建 Fabric，并实现 Underlay 网络自动化部署。<br>2. 创建外部网络，即配置 Fabric 与外部网络的连接关系（连接接口、互联 VLAN、互联地址、对端地址、路由等）。<br>3. 创建网络服务资源，即配置 Fabric 与网络服务资源（DHCP 服务器、RADIUS 服务器、Portal 服务器，以及其他服务器）的连接关系（设备地址、互联 VLAN、互联地址、对端地址、互联端口等）。<br>4. 配置接入管理，即配置接入设备接口，调用认证模板。 |

### 创建 Fabric

首先需要创建 Fabric 并完成基本组网的配置，包括 Border 和 Edge 设备的选取、VXLAN 控制面 BGP EVPN 的配置等。另外，Underlay 网络自动配置路由域功能也是在 Fabric 创建时开启。

| 任务描述 | 详细操作步骤 |
| --- | --- |
| 创建 Fabric | 1. 选择组网类型，包括：集中式和分布式两种。<br>2. 选择无线 WAC 位置，包括：边缘节点、边界网关节点、独立 WAC、不涉及。<br>3. 配置自动配置路由域：开启 Underlay 网络自动配置路由域功能。<br>4. 配置 AS 号：即配置 BGP EVPN，同时设置反射器集群 ID。<br>5. （可选）配置 Fabric 网络风暴抑制。为了减小网络风暴风险，建议配置。<br>6. （可选）开启上报终端识别信息功能。配置终端识别功能时，需要开启。<br>7. 添加设备到 Fabric 网络，并指定设备作为 Border 和 Edge 节点。如果 Fabric 采用的 VXLAN 到汇聚组网，一般还会选取接入交换机作为扩展节点。 |

- Fabric 网络由一组核心-汇聚-接入节点设备互联组成，实现一台接入设备可以同时接入不同的网络业务，节省了成本，并提高了网络设备的利用效率。
- 虚拟化园区网络通过 Overlay 虚拟化技术（VXLAN），实现多个虚拟网络统一承载在同一个 Fabric 网络上，并能够支持业务的灵活部署。
- 组网类型，即 Fabric 的组网部署模式：
  - **集中式**：Fabric 中网关设备是集中的，访问外网和内网的流量都经过集中式的网关。此时，只有边界网关节点可以作为网关。
  - **分布式**：Fabric 中网关设备是分布式的，访问外网和内网的流量经过不同的网关。此时，边界网关节点、边缘节点都可以作为网关。
- iMaster NCE-Campus 支持指定 BGP 路由反射器，并在 Fabric 内所有的边缘节点设备上自动化部署 BGP EVPN 配置。
  - **AS 号**：指定该 Fabric 网络中 BGP 协议的 AS 号。
  - **反射器集群 ID**：路由反射器的集群 ID。如果 Fabric 网络中存在多个路由反射器，如双 Border 组网中配置了两个路由反射器，此时需要配置反射器集群 ID，防止 BGP 路由环路。取值为 1–4294967295 的整数或 IPv4 地址。
- **角色**：指定设备在 Fabric 网络中所属的角色，包含边界网关节点、边缘节点、扩展节点。缺省为扩展节点。
- **路由反射器**：在 Fabric 组网中，一般选择 Border 设备作为路由反射器，简化 IBGP 全互联的需求，也可以减轻网络和 CPU 的负担。
- **自动配置路由域**：开启该功能后，自动配置 Underlay 网络。用户可以指定自动配置路由域的站点，并指定 OSPF 路由参数，当前支持的参数如下：
  - **域**：单域为所有设备均属于 Area 0；多域指所有 Edge 节点位于不同的非骨干区域，Border 节点之间通过骨干区域（Area 0）互联。
  - **网络类型**：指定 OSPF 的网络类型，可以选择 broadcast、P2MP 或者 P2P。
  - **加密**：设置相邻设备之间的加密方式，可以选择 HMAC-SHA256、MD5 或者无。
  - **Key**：接口密文验证的验证字标识符，必须与对端的验证字标识符一致。整数形式，取值范围是 1～255。
  - **密码**：指定密文验证字，字符串格式，不支持空格，长度为 1～255。
  - **确认密码**：确认密文验证字。
  - **OSPF 平滑启动**：开启 OSPF GR 功能。

完成 Fabric 创建后，可实现 Underlay 网络的自动部署，实现建立 Fabric BGP-EVPN 所需的 VLANIF 接口、Loopback 接口、VTEP IP、路由等配置的自动发放。iMaster NCE-Campus 会从 Fabric 全局资源池和 Underlay 自动化资源池内自动分配相关资源给设备。

### 创建外部网络

在 Fabric 网络的资源模型设计中，通过在 Border 节点创建外部网络，使得园区内部终端能够访问外部 Internet 等。

外部网络资源定义了三种类型，如果用户网关位于 Fabric 内，主要采用 L3 共享出口或者 L3 独占出口两种类型。

- **L3 共享出口**：Fabric 网络的多个 VN 共享 L3 出口，与出口设备互通。L3 共享出口可以节省 VLAN 和 IP 等用于互联的资源，适用于不同 VN 间安全控制策略要求较低的场景。
- **L3 独占出口**：Fabric 网络的每个 VN 独占一个 L3 出口，与出口设备互通。此时，防火墙通常会划分多个安全区域与 L3 独占出口一一对应，到达防火墙的不同 VN 间业务子网流量是隔离的。

| 任务描述 | 详细操作步骤 |
| --- | --- |
| 创建外部网络 | 1. 选择与外部网络连接类型。<br>2. 选择外部网络资源类型。<br>3. 配置互联的物理接口，以及互联的 VLAN 和 IP 地址。<br>4. 配置互联的路由协议。 |

创建一个新的 Fabric 外部网络，选择出口连接方式。

> （原图：外部网络资源与 HQ Border、ACC、ACC_2、AP1、iMaster NCE 的连接示意；可选共享出口。）

- 说明：“连接 Internet”开关若被激活，则意味着控制器将使用一条默认路由来引导流量去往对应的外部网络。如果该开关不激活，则用户需要指定具体的路由前缀。
- **互联信息**：
  - 选择连接外部网络的 Border 设备，选择去往外部网络的接口、互联地址、互联 VLAN 等。
  - 注意：此时配置的互联地址，不能与 Underlay 自动化资源池冲突。此时配置的互联 VLAN，属于 Fabric 全局资源池。
- **路由信息**：
  - 点击“应用”后，控制器将会为 Border 设备创建去往外部网络的静态路由（当且仅当该外部网络被虚拟网络调用时，静态路由才会下发到 Border 上）。

### 创建网络服务资源

在 Fabric 网络的资源模型设计中，通过在 Border 节点创建网络服务资源，使得园区内部业务终端能够访问网络管理区的服务资源，比如 DHCP 服务器、准入服务器等。

- 网络服务资源可以创建多个，也可以一个网络服务资源模型包含多个服务资源的访问地址。
- 如果网络管理区需要访问的服务资源较少，建议这些服务资源都规划在一个网络服务资源模型中。这样，可以节省互联的 VLAN 和 IP 地址资源，简化网络管理区的路由配置。

| 任务描述 | 详细操作步骤 |
| --- | --- |
| 创建网络服务资源 | 1. 选择服务器类型，包括：DHCP、第三方 RADIUS 服务器、第三方 Portal 服务器和其他。<br>2. 配置服务资源的访问地址，如 DHCP 服务地址、iMaster NCE-Campus 的南向地址。<br>3. 选择互联场景，包括：直连服务器、直连交换机。<br>4. 配置互联的物理接口，以及互联的 VLAN 和 IP 地址。 |

- **服务器配置**：
  - **服务器类型**：该网络服务资源所关联的服务器资源。在本例中，我们所定义的网络服务资源是 DHCP 服务器和 E-mail 服务器。
  - **DHCP 服务器**：配置网络中的 DHCP 服务器地址，包括 IPv4 及 IPv6 地址。
  - **服务器互通源地址池**：如果 DHCP 服务器中配置了 IPv6 地址池，此处必须配置；如果 DHCP 服务器仅配置了 IPv4 地址，则此处可以不用配置。
- **设备配置**：
  - **场景**：如果选择“直连交换机”，则 Border 将互联端口以 Tagged 方式加入互联 VLAN，连接网络资源；如果选择“直连服务器”，则交换机将互联端口以 Untagged 方式加入互联 VLAN。
  - **互联设备**：选择核心交换机 Border。该设备将作为边界网关，连接 Fabric 网络，以及网络外部的服务资源。
  - **互联端口**：选择核心交换机 Border 上去往网络服务资源的接口。
  - **互联 VLAN**：选择核心交换机 Border 上去往网络服务资源的 VLAN。
  - **互联 IPv4 或互联 IPv6**：核心交换机上，用于连接网络服务资源所在网络的本地接口地址。
  - **对端 IPv4 或对端 IPv6**：对端设备的地址。
  - **掩码**：网络掩码。
- 注意：此时配置的互联地址，不能与 Underlay 自动化资源池冲突。此时配置的互联 VLAN，属于 Fabric 全局资源池。

### 配置接入管理

园区网络需要部署准入控制对接入用户进行认证，包括 802.1X 认证、MAC 认证和 Portal 认证，其中 802.1X 认证及 MAC 认证在实现中需 RADIUS 认证服务器配合，而 Portal 认证则需 RADIUS 服务器和 Portal 服务器配合。

- Fabric 的接入管理主要是配置认证控制点，对接入点资源进行规划，在 VN 创建时会被选用。
- 其中，有线接入点资源指的是终端接入的交换机端口，无线接入点资源指的是终端接入的 SSID。
- Fabric 接入管理中，对交换机的接入端口定义了 3 种连接类型：
  - **Fabric 扩展 AP**：华为瘦 AP，可以通过 iMaster NCE-Campus 进行管理。
  - **Fabric 扩展接入交换机**：华为交换机，可以通过 iMaster NCE-Campus 进行管理。
  - **终端（PC、话机、哑终端、非 Fabric 扩展交换机/AP）**：用户终端、不支持 iMaster NCE-Campus 管理的交换机和 AP、支持 iMaster NCE-Campus 管理但不支持 Fabric 扩展的交换机。
- 在不同的网关方案中，Fabric 接入管理的配置会有差异。

- **策略联动**：
  - 配置策略联动管理 VLAN 和策略联动管理 IP。
  - 此时配置的管理 IP，不能与 Underlay 自动化资源池冲突。此时配置的管理 VLAN，属于 Fabric 全局资源池。

Fabric 创建完成后，就可以选取其中的网络资源，创建 VN 实例。若不同 VN 的接入用户想要互访，还需要配置 VN 互通。

| 任务描述 | 配置步骤 |
| --- | --- |
| 逻辑网络 | 1. 创建 VN，不同的 VN 代表不同用户的业务，通过 VN 实现业务隔离。<br>2. 配置 VN 互通，实现不同用户底层路由可达。 |

### Fabric 资源池与创建 VN 时的资源调用

| Fabric 包含的资源池 | 创建 VN 时如何调用资源池中的资源 |
| --- | --- |
| VLAN 资源池：VN 接入终端、与外部互联等场景使用，配置 Fabric 全局资源池时规划。 | 在 VN 中创建用户网关时，设置的用户 VLAN 为 Fabric 全局资源池中的资源。 |
| BD/VNI 资源池：VN 中划分的二层广播域，对应的 VBDIF 接口作为用户子网网关接口，配置 Fabric 全局资源池时规划。 | 在 VN 中创建用户网关时，会自动从 BD/VNI 资源池中调用资源，创建 BD 广播域及对应的 VBDIF 接口。 |
| 用户接入点资源池：配置 Fabric 的接入管理时规划，包括接入点绑定的认证方式。 | 在 VN 中配置用户接入时，可选取已规划的接入点资源。 |
| 外部出口池：指 VN 可以使用的外部资源，配置 Fabric 时主要创建两类：外部网络（用于 VN 与外部互通）；网络服务资源（用于 VN 与认证服务器、DHCP 服务器等互通）。 | 创建 VN 时，可选取外部网络和网络服务资源。 |

### 创建 VN

创建 VN，实际上是创建对应的 VPN-Instance，实现不同业务的隔离。

| 任务描述 | 详细操作步骤 |
| --- | --- |
| 创建 VN | 1. （可选）选择网络服务资源。通常会选取，用于 VN 与网络服务资源互通。<br>2. （可选）选择外部网络。通常会选取，用于 VN 与外部网络互通。<br>3. 配置用户网关，有手动指定和自动分配两种方式可选择。<br>4. 配置用户有线接入（选取已规划的接入点）。<br>5. 配置用户无线接入，选择接入无线用户子网的 AC 设备，然后用户网关中配置的业务 VLAN 会下发到该设备。 |

创建一个新的 VN，定义 VN 的名称、用户网关位置，并可配置 VN 所使用的外部网络及网络服务资源。

> （原图：新建 VN——RD 虚拟网、OA 虚拟网；HQ Border、ACC_2、AP1、PC1、PC3 与外部网络、网络服务资源关系。）

定义 VN 的用户网关，网络管理员可以通过手动指定的方式逐个创建用户网关，也可以通过自动分配的方式批量创建用户网关。

> （原图：VN 接入用户网段规划——Sales_Wired 172.17.10.0/24、Sales_Wireless 172.17.11.0/24、Market_Wired 172.17.20.0/24、Market_Wireless 172.17.21.0/24、RD 172.17.30.0/24。）

- **用户接入配置**维护的是当前 VN 的接入点。
- **用户有线接入**：由于希望 OA 虚拟网络的有线用户能够从 ACC_1 和 ACC_2 接入进来，并且都需要进行认证，因此配置用户有线接入时选择这两台交换机相应开启了认证的接口。
- **用户无线接入**：在无线接入配置中选择 Border，Border 是一台具备随板 AC 功能的交换机，它将通过 AC 管理下面的 AP 设备，提供无线接入。

### VN 互通

缺省情况下，VN 之间完全隔离，但是在某些特殊情况下，我们可能希望 VN 之间能够互访，则需要将 VN 之间的路由打通。

配置 VN 互通，实际是创建对应 VPN Instance 的静态路由，使得不同 VN 接入用户能够在路由层面互访。

| 任务描述 | 详细操作步骤 |
| --- | --- |
| 配置 VN 互通 | 1. 选择互通设备。<br>2. 选择互通方式，包括全互通和部分互通。<br>3. 配置源 VN、源 IPv4 前缀、目的 VN、目的 IPv4 前缀。 |
