# 1.1 IGP 高级特性

> （原文 1.1.1 实验介绍开头 OCR 缺失；正文从现有任务与配置步骤续接。）

## 1.1.2 实验任务

1.1.2.1 配置思路

1. 设备IP 地址配置。
2. 按照规划配置OSPF。
3. 按照规划配置IS-IS。
4. 调整PE2-PE1 之间的OSPF 接口Cost 值，使得PE2 访问P1 优先走PE1，并在PE2 上开启 OSPF IP FRR，生成访问P1 的备份路径。
5. OSPF 域内开启BFD，加速OSPF 故障收敛。
6. PE1、P2 上创建IP 地址相同的Loopback2 接口，均在该接口上激活OSPF，在P1 上查看 OSPF 路由表中是否存在等价路由，之后限制等价路由为1。在PE3 上创建接口Loopback3 并激活OSPF，在ABR P1 上配置区域间路由过滤，限制PE3 Loopback3 接口路由向Area 0 内传递。
7. 在PE3 IS-IS 进程1 中发布缺省路由。
