# 10.1 SSH 实验

## 10.1.1 实验介绍

10.1.1.1 学习目标

- 实现使用paramiko 模块SSH 登录设备
- 实现使用paramiko 登录设备查看相关配置以及传输文件

## 10.1.2 实验任务

10.1.2.1 配置思路

1. ACC_1 基础配置。
2. 完成ACC_1 的SSH 配置，创建对应的SSH 用户并生成PC1 的公、私钥，上传到ACC_1， 配置使用公钥登录的SSH。
3. 编写SSH 登录设备的脚本并执行
4. 脚本解析。
5. 完成ACC_1 的SFTP 配置。
6. 编写SFTP 代码。
7. 脚本执行与解析。

import paramiko import time

ssh = paramiko.SSHClient() ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy())

ssh.connect(hostname='192.168.100.254',port=22,username='python',key_filename=r'C:\Users\PC1\Documents\Key \SSH\id_rsa')

cli = ssh.invoke_shell() cli.send('screen-length 0 temporary\n') cli.send('display version\n') time.sleep(1) dis_ver = cli.recv(999999).decode()

cli.send('display memory-usage\n') time.sleep(1) dis_mem = cli.recv(999999).decode()

cli.send('display cpu-usage history 1hour\n') time.sleep(1) dis_cpu_usage = cli.recv(999999).decode()

print(dis_ver) print("-----------------------------------------------") print(dis_mem) print("-----------------------------------------------") print(dis_cpu_usage) print("-----------------------------------------------")

ssh.close()
